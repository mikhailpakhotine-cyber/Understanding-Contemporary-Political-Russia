## Reading Tips

### How to Read the Textbook Effectively
1. Preview the chapter (headings, summaries)
2. Read actively (take notes, highlight key points)
3. Note key terms and concepts
4. Pay attention to examples
5. Review end-of-chapter materials
6. Connect to lecture content
7. Prepare discussion questions

### Focus Points in Each Chapter
- Main arguments
- Key concepts and definitions
- Historical context
- Contemporary applications
- Comparative perspectives (Russia vs. U.S.)
- Critical analysis

### End-of-Chapter Materials
Most chapters include:
- Discussion questions
- Web exercises
- Suggested readings

**Note**: Reading Reflection assignment uses these end-of-chapter materials

## Using Textbook for Assignments

### For Exams
- Review all assigned chapters thoroughly
- Create study guides from chapter content
- Focus on key concepts and arguments
- Understand examples and applications

### For Reading Reflection
- Choose discussion questions OR web exercise
- Engage deeply with chapter content
- Cite chapter in your essay

### For Travel Itinerary
- Textbook may be one of your sources
- Provides context for Russian culture and society
- Can supplement with other sources

### For Class Participation
- Complete readings before class
- Prepare questions for discussion
- Reference readings in contributions
