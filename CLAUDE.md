## Project Overview

This repository contains course materials for **INS 3XXX: Understanding the Society of Contemporary Russian Federation**, a Fall 2024 course at Embry-Riddle Aeronautical University. The repository is organized to support both instructor preparation and student learning.

## Repository Structure

The repository is organized into the following main directories:

- **`weeks/`** - Weekly course materials (15 weeks total, excluding holidays)
- **`assignments/`** - Assignment guidelines, rubrics, and templates
- **`exams/`** - Exam study guides and materials (3 exams)
- **`readings/`** - All course readings organized by source type
- **`lectures/`** - Lecture materials organized by topic
- **`resources/`** - Supporting materials (bibliography, rubrics, citation guides, tools)
- **`policies/`** - Course policy documents

## Course Topics (By Week)

The course covers 11 content weeks (4 weeks are holidays):

1. Introduction/Overview (Week 1)
2. History, Communism, and Its Demise (Week 3)
3. Executive Branch and Federalism (Week 4)
4. Political Culture (Week 5, with Exam #1)
5. Legislative Branch (Week 6)
6. Parties, Elections, and Participation (Week 7)
7. Judicial Branch and Human Rights (Week 9, with Exam #2)
8. Economic Transition and Policy (Week 10)
9. Social Policy (Week 12)
10. Foreign and Security Policy (Week 14)
11. Future Trends and Projections (Week 15, with Exam #3)

## Key Files

## Weekly Folder Structure

Each week folder contains:
- `README.md` - Week overview and learning objectives
- `lecture-notes.md` - Lecture content
- `readings.md` - Required readings with references
- `activities.md` - Discussion questions and in-class activities
- `resources.md` - Additional materials and links

## Assignment Structure

Three main assignments:
1. **Reading Reflection** (5 points) - 1-2 page essay, due varies
2. **Travel Itinerary** (20 points) - 5-7 page themed research paper, due Nov 18
3. **Class Participation** (15 points) - Ongoing throughout semester

## Exam Structure

Three exams (20 points each):
- **Exam #1** - September 23 (covers weeks 1-4)
- **Exam #2** - October 21 (covers weeks 5-7)
- **Exam #3** - December 9 (final exam period)

## Textbook

Primary text: Shiraev, E. (2013). *Russian Government and Politics, 2nd Edition*. Palgrave Macmillan/St. Martin's Press.

## Working with This Repository

### Adding New Content

When adding materials:
1. Place weekly content in appropriate `weeks/week-XX-topic/` folder
2. Update relevant README files to maintain navigation
3. Add citations to `resources/bibliography/` organized by week
4. Place reusable rubrics in `resources/rubrics/`

### File Naming Conventions

- Week folders: `week-XX-topic-name/` (e.g., `week-03-history-communism/`)
- Standard files in each week: `README.md`, `lecture-notes.md`, `readings.md`, `activities.md`, `resources.md`
- Use lowercase with hyphens for file/folder names

### Bibliography Organization

Bibliography is organized by week in `resources/bibliography/`:
- `week-01.md`, `week-03.md`, etc.
- Each file contains all sources referenced that week
- Follow consistent citation format (APA or MLA)

### Maintaining Consistency

- All markdown files should include clear headers
- Cross-reference related materials using relative links
- Update main README.md when adding new major sections
- Keep COURSE_SCHEDULE.md aligned with week folder contents
