## Using Lecture Materials

## Lecture Notes

### Student Responsibilities
- Attend all lectures
- Take comprehensive notes
- Review notes after class
- Fill gaps with readings
- Compare notes with classmates

### Note-Taking Tips
1. Don't try to write everything
2. Focus on main concepts
3. Note examples
4. Mark unclear points
5. Review within 24 hours
6. Expand abbreviations
7. Add connections to readings
