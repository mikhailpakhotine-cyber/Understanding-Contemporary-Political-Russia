# Course Tools and Utilities

## Overview
This directory contains helpful tools, templates, and utilities for managing course work.

## Study Tools

### Flashcard Templates
- Create flashcards for key terms
- Study for exams
- Review concepts

### Study Guide Templates
- Organize notes by topic
- Prepare for exams
- Track learning

### Note-Taking Templates
- Structured note formats
- Reading notes
- Lecture notes

## Organization Tools

### Assignment Tracker
Track all assignments and deadlines:
- Reading Reflection - Due varies (check Canvas), latest Dec 2
- Travel Itinerary - Due Nov 18, 11:59 PM
- Exam #1 - Sept 23
- Exam #2 - Oct 21
- Exam #3 - Dec 9

### Reading Checklist
Track completion of all assigned readings by week

### Bibliography Tracker
Keep track of sources for research paper:
- Source name
- Citation information
- Notes
- Relevance to theme

## Research Tools

### Source Evaluation Checklist
Evaluate whether sources are appropriate:
- Author credentials?
- Publication date?
- Reputable publisher?
- Peer-reviewed?
- Objective?
- Well-documented?

### Travel Itinerary Planning
- Theme brainstorming worksheet
- Site research template
- Itinerary organization outline

## Writing Tools

### Citation Checklist
- All sources cited?
- Consistent style (APA or MLA)?
- Complete references?
- Page numbers for quotes?
- No Wikipedia?

### Proofreading Checklist
- Grammar and spelling?
- Paragraph development?
- Transitions?
- Thesis clear?
- Evidence supports claims?
- Citations correct?
- Length requirements met?
- Format correct?

### Revision Checklist
- Content complete?
- Organization logical?
- Arguments clear?
- Evidence sufficient?
- Writing polished?
- Citations accurate?

- Schedule reading time

## Tips for Success

### Start Early
- Don't procrastinate
- Break big assignments into steps
- Use deadlines effectively

### Stay Organized
- Keep all materials together
- Track assignments
- Maintain calendar
- File readings and notes

### Use Resources
- Attend office hours
- Visit Writing Center
- Use library
- Join study groups

### Self-Monitor
- Check your understanding
- Assess your participation
- Track your grades
- Adjust as needed

## Questions?
- Most tools are self-explanatory
- Adapt to your learning style
- Ask for help if needed
- Share useful tools with classmates
